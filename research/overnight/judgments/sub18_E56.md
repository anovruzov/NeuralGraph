## 3. Premise checks

### 3a. 778164c6: is the mango memory missing from the variant context?

No. It is active and present in both runs.

| run | mango memory | other candidates | answer |
|---|---|---|---|
| base (15 memories) | rank 3, "Grilled Snapper with Mango Salsa ... fruity and spicy salsa" | rank 2, "recommended Escovitch Fish first" | Mango (correct) |
| E56 (11 memories) | rank 4, same text | rank 2 "plans to try Escovitch", rank 3 "recommended Escovitch first" | Escovitch (wrong) |

The variant reader matched on "recommended" and ignored "fruit". Answer-level regression, context unchanged in substance. Single sample at temp 0.

### 3b. 0f05491a: did the variant context hold 120 where the baseline had 300 or 125?

Yes. The variant context has 120 at rank 1. The baseline has only 300 at rank 2. The 125 figure is only in an assistant quote in the baseline source_quotes, and the baseline store has no 125 memory.

The baseline audit_log shows why. The user's 120 correction (2023-07-30) was logged as `duplicate, how=reconcile` against the 300 memory and never stored. The variant stored it as the newest update in a chain (300, 400, 125 superseded; 120 active). This is the numeric-dedupe failure that `num_dedupe` targets. Real-fix, context changed.
