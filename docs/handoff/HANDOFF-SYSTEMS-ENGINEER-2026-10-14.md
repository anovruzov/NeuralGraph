## 6. What I would propose, if you want my view

1. **Pin (a).** The end-to-end `recall_all`, lower 95% bound ≥ 0.80, over 5 fresh worlds at size 200, hierarchy
   only, k = 3 kept. Report 600 and 2,000 beside it.
2. **First lever: recover rare patterns without lowering k.** HQ sends each site a targeted question about one
   (entity, chain) pair it already suspects. The site answers only a count at or above k, or "below k", never a
   record. The simulator's own finding is that the downward path is where discovery comes from: sketch-driven
   questioning took discovery from 2% to 57% (`MYCELIC_ENTERPRISE.md` section 1, decision 2).
3. **Second lever: decoy defences for classes 2 and 4.**
   - Class 2 (temporal scramble): add the time order to the chain key.
   - Class 4 (duplicate inflation): count independent witnesses rather than mentions. The simulator's
     independent-support check is 77% accurate for the hierarchy (section 1 table).
4. **Third: measure each lever alone on development seeds.** Then fix the design and run the held-out seeds once.
   The first held-out run is the result.

I will not claim any of this works until the held-out run says so.
