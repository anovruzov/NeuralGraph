## Executive Summary

MemMachine is a **brain-inspired memory architecture** for conversational AI that achieves **70.5% accuracy** on the LoCoMo benchmark with **100% adversarial detection**. The system uses a novel **4D Tesseract** design with four specialized memory stores modeled after brain regions:

| Store | Brain Region | Function | Accuracy |
|-------|--------------|----------|----------|
| **Temporal** | Hippocampus | "When did X happen?" | 45.2% |
| **Entity** | Neocortex | "What/Who is X?" | 52.1% |
| **Reasoning** | Prefrontal Cortex | Multi-hop inference | 74.0% |
| **Adversarial** | Orbitofrontal Cortex | Negation/verification | 100.0% |

## 4D Tesseract Architecture

### Query Type Detection

```python
def detect_query_type(query: str) -> dict[QueryType, float]:
    """Detect query type using pattern matching."""
    scores = {
        QueryType.TEMPORAL: 0.0,
        QueryType.ENTITY: 0.0,
        QueryType.MULTI_HOP: 0.0,
        QueryType.ADVERSARIAL: 0.0,
        QueryType.OPEN: 0.2,  # Default baseline
    }

    # Temporal patterns
    if re.search(r'\b(when|what time|what date|before|after)\b', query, re.I):
        scores[QueryType.TEMPORAL] += 0.6

    # Entity patterns
    if re.search(r'\b(what|who|which|where)\b', query, re.I):
        scores[QueryType.ENTITY] += 0.4

    # Multi-hop patterns
    if re.search(r'\b(why|how|because|therefore|relationship)\b', query, re.I):
        scores[QueryType.MULTI_HOP] += 0.5

    # Adversarial patterns
    if re.search(r'\b(never|not|didn\'t|wasn\'t|false|incorrect)\b', query, re.I):
        scores[QueryType.ADVERSARIAL] += 0.7

    return scores
```

### Electron Propagation

The electron system simulates neural activation:

```python
class Electron:
    node_id: str
    energy: float           # Decays with each hop
    phase: float            # For interference patterns
    wave_signature: dict    # Inherited from query
    hops_remaining: int
    path: list[str]         # Traversal history

async def propagate_step(self):
    for electron in self._electrons:
        edges = await self._storage.get_edges_from(electron.node_id)

        for edge in edges[:6]:  # Fan-out limit
            new_energy = electron.energy * edge.effective_weight
            if new_energy > THRESHOLD:
                new_electron = Electron(
                    node_id=edge.target_id,
                    energy=new_energy,
                    phase=electron.phase + PHASE_SHIFT,
                    hops_remaining=electron.hops_remaining - 1
                )
                self._electrons.append(new_electron)
```

## Key Algorithms

### 1. Temporal Chain Building

```python
async def build_temporal_chain(nodes: list[NeuralNode], session_key: str):
    """Create TEMPORAL edges between consecutive messages."""
    sorted_nodes = sorted(nodes, key=lambda n: n.created_at)

    for i in range(len(sorted_nodes) - 1):
        prev_node = sorted_nodes[i]
        curr_node = sorted_nodes[i + 1]

        time_diff = (curr_node.created_at - prev_node.created_at).total_seconds()
        weight = math.exp(-time_diff / (7 * 24 * 3600))  # 7-day decay

        edge = NeuralEdge(
            source_id=prev_node.node_id,
            target_id=curr_node.node_id,
            edge_type=EdgeType.TEMPORAL,
            base_weight=weight,
        )
        await storage.save_edge(edge)
```

### 2. Adversarial Detection

```python
def detect_negation(query: str, context: str) -> bool:
    """Detect if query contains negation that contradicts context."""
    negation_patterns = [
        r'\bnever\b', r'\bnot\b', r'\bno\b',
        r'\bdidn\'t\b', r'\bwasn\'t\b', r'\baren\'t\b',
        r'\bfalse\b', r'\bincorrect\b', r'\bwrong\b'
    ]

    has_negation = any(re.search(p, query, re.I) for p in negation_patterns)

    if has_negation:
        # Check if context AFFIRMS what query NEGATES
        # Return context that contradicts the negation
        return verify_against_context(query, context)

    return False
```

### 3. Wave Amplitude Analysis

```python
WAVE_DIMENSIONS = {
    "temporal": ["when", "time", "date", "before", "after"],
    "entity": ["who", "what", "which", "name"],
    "relational": ["between", "with", "relationship"],
    "action": ["did", "do", "doing", "verb"],
    "state": ["is", "was", "were", "be"],
    "spatial": ["where", "location", "place"],
    "causal": ["why", "because", "therefore", "cause"],
    "emotional": ["feel", "happy", "sad", "angry"],
    "quantitative": ["how many", "how much", "count"],
}

def compute_wave_amplitudes(text: str) -> dict[str, float]:
    """Compute 9D wave signature from text."""
    amplitudes = {}
    text_lower = text.lower()

    for dimension, keywords in WAVE_DIMENSIONS.items():
        score = sum(1 for kw in keywords if kw in text_lower)
        amplitudes[dimension] = min(1.0, score / len(keywords))

    return amplitudes
```

## Known Limitations & Future Work

### Critical Missing Components

| Component | Status | Impact | Priority |
|-----------|--------|--------|----------|
| **Temporal Anchors** | NOT IMPLEMENTED | temporal: 45%->65% | HIGH |
| **Dialogue Linking** | DISABLED | single_hop: 52%->70% | HIGH |
| **Query Router** | DISABLED (regression) | 10-15% overall | HIGH |
| **Topic Clustering** | NOT IMPLEMENTED | Abstraction retrieval | MEDIUM |
| **Persona Modeling** | NOT IMPLEMENTED | User preferences | LOW |

### Unused Computed Data

| Data | Location | Issue |
|------|----------|-------|
| Wave Amplitudes | Every node | Only used in routing, not scoring |
| Importance Score | Every node | Ignored by electron/flash retrieval |
| Phase Coherence | Electrons | Computed but never ranked |
| Heat Scores | Consolidation | Ignored in retrieval |
| Relation Types | KG edges | Stored but never weighted |

### Recommended Improvements

1. **Enable Temporal Anchors**
   - Create `TEMPORAL` layer nodes for dates
   - Link messages to their temporal anchors
   - Enable temporal queries to resolve to date nodes

2. **Enable Dialogue Linking**
   - Set `dialogue_linking_enabled = True`
   - Tune aggregator parameters
   - Use Q+A pairs as atomic retrieval units

3. **Fix Query Router**
   - Debug the 30% vs 85% regression
   - Enable entity/temporal pre-filtering
   - Route queries to specialized stores earlier

4. **Connect Gating to Electrons**
   - Import `EdgeGateRegistry` into `electron.py`
   - Apply gate values during propagation
   - Sort edges by gated strength, not arbitrary order

5. **Increase Entity Expansion Hops**
   - Change `max_hops=1` to `max_hops=3` in entity_expansion stage
   - Match temporal chain's 3-hop traversal
